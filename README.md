# 雨夜轻息取词器

Windows 桌面程序，为 Wallpaper Engine 工坊场景《雨夜轻息》（作品编号 `3842256065`）提供逐句歌词。适用于支持 Windows 系统媒体控制的播放器。此版为 Windows 10 1809 及以上、Windows 11 的 x64 版本。

## 使用

1. 在 Wallpaper Engine 中应用工坊场景《雨夜轻息》，打开壁纸属性里的「顶部音乐胶囊」。双击 **RainNightLyrics.exe**，回到桌面。胶囊右侧的小唱片就是取词器。
2. **网易云音乐 Windows 客户端**是当前支持自动查词的音乐软件。客户端需要向 Windows 媒体控件报告正在播放音乐。第一次播放时，小唱片会展开。正在使用其他应用时，唱片显示「等你选择」，回到桌面或点击唱片即可看到询问框。选择 **自动查词** 后，换歌会自动查询。选择 **暂不** 或关闭对话框，会记住这个选择。
3. **浏览器中的 B 站、网易云网页版和其他播放器**可以逐首手动查。右键唱片，选 **为当前播放查一次歌词…**，核对预填歌名，必要时改成准确的歌名再确认。这次确认只用于当前媒体。网易云客户端报告视频、未知媒体或其他非音乐类型时，也使用手动模式。
4. 右键菜单中的 **自动查词（音乐软件）** 随时可以切换。关掉后会取消正在进行的查询，仍可为当前播放手动查一次。点唱片可看状态，显示「歌词已同步」后胶囊会跟随进度换词。

按住唱片拖动可以调整位置，右键选 **回到默认位置** 可以复位。多屏使用同一场景时，唱片跟随第一个匹配的屏幕。唱片匀速旋转最高 60 帧/秒，展开、收起和换句跟随停靠屏幕的刷新率。右键选 **关闭取词器** 可以退出。

连续换歌时，取词器直接向当前场景发送新歌数据。支持协议 2 的壁纸收到清空指令后，会回到歌名和歌手。配合旧版壁纸时，停播、关闭自动查词或退出可能需要重新载入场景。旧版播放列表保留现有列表，恢复播放后若仍显示旧词，可重新应用壁纸。

## 蓝牙耳机重连后恢复音柱

保持取词器运行，将 Wallpaper Engine 设置里的「录音设备」选为「默认」。AirPods 重新连接、拔插 USB 耳机或切换到扬声器后，程序会等默认输出稳定约 3 秒，再检测是否有声音。连续两次测到声音后，它会在使用《雨夜轻息》的屏幕上重新载入当前场景。耳机出声后，音柱可能再过几秒才出现，歌词会按播放器的当前进度继续。

暂停或静音时，程序会等到声音恢复。手动指定录音设备、使用其他壁纸或屏幕配置中标有播放列表时，会跳过自动重载。设备通知和音量峰值只在本机处理，取词器不保存音频。

## 测试时

- 「等待播放」表示当前没有可读取的媒体。可以先播放歌曲，确认系统媒体控件能看到曲名，再回桌面。可用的网易云版本如果提供「系统媒体控制」选项，请打开该选项。
- B 站提供的是视频标题，有明确歌名的单曲最容易匹配。合集、翻唱、纯音乐或曲库缺词时，胶囊可能显示歌名。如果播放器没有提供时间轴，逐句同步取决于壁纸能否获得播放进度。
- 若程序显示已送到壁纸而画面静止，可回到桌面检查。Wallpaper Engine 设置为在其他窗口最大化时暂停，会同时暂停胶囊动画。
- 在程序目录执行 `.\RainNightLyrics.exe --check`，可以查看匹配屏幕数、唱片绘制帧率、当前媒体的应用 ID 和分类。要反馈新播放器，只需应用 ID。执行 `.\RainNightLyrics.exe --stop` 可退出当前实例。

## 数据如何流动

Windows 提供当前播放器的应用 ID、播放状态和媒体类型。只有白名单客户端报告正在播放音乐，且你已同意时，才会自动查词。浏览器和其他播放器在你打开手动查询后预填候选，你可以在发送前修改。

0.4.0 向网易云曲库和 LRCLIB 搜索时只发送歌名。音乐软件使用播放器报告的歌名，手动查询使用你在对话框确认的文字。歌手、时长与曲库返回的候选在本机核对。取词器不会把浏览记录、页面地址、封面或系统音频作为查询数据发送。取消会停止后续请求，已经到达曲库的请求无法撤回。

歌词、封面和当前歌曲的确认状态保存在内存中。本机状态日志只含固定的运行状态和曲库名称，位于 `%LOCALAPPDATA%\RainNightLyrics`，达到 256 KB 时轮换。`%APPDATA%\RainNightLyrics\settings.json` 保存显示器的拖动偏移和 `autoLookup` 选择。这个键缺失表示尚未选择。在 exe 旁创建 `portable-data` 文件夹，可以把设置和日志留在程序旁边。

取词器通过本机 Wallpaper Engine 的 `applyProperties` 把媒体标题、时间轴和歌词发送到应用《雨夜轻息》的屏幕。它按工坊编号识别场景，支持跨磁盘的 Steam 库。壁纸侧的协议版本记录在订阅项目的 `project.json` 顶层整数 `capsuleprotocol` 中。[Wallpaper Engine 命令行文档](https://help.wallpaperengine.io/en/functionality/cli.html#apply-wallpaper-settings) · [Windows 媒体接口](https://learn.microsoft.com/en-us/uwp/api/windows.media.control.globalsystemmediatransportcontrolssessionmanager) · [LRCLIB 接口](https://lrclib.net/docs)

## 从源码构建

在 Windows x64 安装 Rust 的 MSVC 工具链和 Visual Studio C++ 构建工具。在工程目录运行以下命令，本机验证使用 Rust 1.93。

```powershell
cargo test --release --locked
cargo build --release --locked
```

可执行文件生成在 `target\x86_64-pc-windows-msvc\release\rain-night-lyrics.exe`。
